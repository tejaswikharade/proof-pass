# Security policy

ProofPass is an educational reference implementation and has not been audited. Do not use it to store production credentials or protect sensitive data.

## Reporting a vulnerability

Please do not open a public issue for a potential vulnerability. Send a concise report, reproduction steps, and the affected contract function to [tejaswisampat1898@gmail.com](mailto:tejaswisampat1898@gmail.com).

## Scope

Reports about authorization checks, credential revocation, storage privacy, and event integrity are especially useful. The React demo is not connected to a wallet or a production RPC endpoint.
